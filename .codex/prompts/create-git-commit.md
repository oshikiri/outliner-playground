現在の git 差分を確認して、このリポジトリ向けのコミットメッセージ案を 1 件作成してください。

追加の文脈が渡された場合は、それも踏まえて要約してください。

## 出力要件

- 1 行目に Conventional Commit 形式のコミットメッセージを 1 件だけ出す。
- 2 行目以降では、その prefix を選んだ理由を 1 段落で短く説明する。
- 必要なら、ステージ済み変更と未ステージ変更が混ざっていることを指摘する。
- 実際に `git commit` は実行しない。

## 規約

- `feat:` はユーザーから見える機能追加に使う。
- `fix:` はバグ修正や UI に影響するスタイル修正に使う。
- `test:` はテスト追加やテスト修正に使う。
- `docs:` はドキュメントやコメントの変更に使う。
- `refactor:` は挙動を変えない内部整理に使う。
- `chore:` は依存更新、ツール調整、保守作業に使う。
