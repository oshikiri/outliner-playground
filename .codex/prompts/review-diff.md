現在の git 差分に対して差分レビューを実施してください。

追加の文脈が渡された場合は、それも踏まえてレビューしてください。

## 実施方針

- まず `git status --short` を確認して、作業ツリー全体の変更状態を把握する。
- `git diff` で未ステージ変更を確認する。
- `git diff --cached` でステージ済み変更を確認する。
- `git ls-files --others --exclude-standard` で untracked file を確認し、必要な関連ファイルも読む。
- サブエージェントが利用できる環境では、review_manager サブエージェントを使って差分レビューを依頼する。
- サブエージェントが利用できない環境では、自分で通常の差分レビューを行う。
- レビューでは、バグ、仕様逸脱、回帰、テスト不足、保守上のリスクを優先して確認する。
- ドキュメントのみの差分でも、記述の整合性や運用上の問題がないか確認する。
- 実際のコード修正や `git commit` は行わない。

## 出力要件

- 指摘がある場合は、重要度順に列挙する。
- 各指摘には、対象ファイルと該当箇所を含める。
- review_manager から結果が返った場合は、省略せずにすべて表示する。
- 指摘がない場合は、そのことを明記する。
- 最後に、必要なら未確認事項や前提を短く補足する。
