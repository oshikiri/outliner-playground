# Outliner Editor

この仕様は、Outliner Editor の挙動を説明する。
基本的にLogseqの挙動をベースにする。

## 用語

- block: 本文テキストを持ち、親子関係を持てる編集単位とする。各 block は 0 個以上の子 block を持てる。
- BlockComponent: 画面上で各 block を表示・編集する UI 単位とする。

## Blockの木構造

- このエディタの block は tree 構造を成す。
- [OE-TREE-001] この tree には、画面に表示しない hidden root が存在する。
  - エディタは hidden root 自体を表示せず、その子ブロックを表示する。
- [OE-TREE-002] 走査順は、特に断りがない限り pre-order depth-first とする。

## モード

各 BlockComponent には、以下の三種類のモードがある。

- 編集モード: そのブロックの markdown テキストを編集できる。
- 表示モード: そのブロックの markdown を閲覧用にレンダリングする。
- 選択モード: ブロック単位の選択状態を表示し、複数ブロックをまとめて操作するためのモードとする。

各 BlockComponent は、この三種類のうち一つのモードにだけ入る。

### モード間遷移の条件

- [OE-MODE-001] 表示モードのブロックを1回クリックしたとき、編集モードに遷移する
  - [OE-MODE-002] あるブロックがクリックされて編集モードに入ろうとしている場合、既存の編集モードのブロックがあればそのブロックは強制的に表示モードになる
- [OE-MODE-003] キャレットがあたっているブロックは編集モードに遷移する
  - この条件はクリックによるキャレット移動だけでなく、キーボード操作によるキャレット移動にも適用する
- [OE-MODE-004] ブロック外をクリックした場合、編集モードに入っているブロックは、変更を保存した上で表示モードになる
- [OE-MODE-006] 表示モードのブロックをクリックして編集モードに入る場合、キャレットはクリック位置に最も近い箇所へ配置する

その他遷移時の挙動

- [OE-MODE-005] 2個以上のブロックが同時に編集モードに入らないこと

## 折りたたみ

子を持つ block は、バレット操作で子要素の表示を折りたためる。
折りたたみ状態は block ごとの文書データとして扱う。

- [OE-COLLAPSE-001] 子を持つ block のバレットをクリックしたとき、折りたたみ状態と展開状態が切り替わる
  - バレット表示も対応して切り替わる
- [OE-COLLAPSE-002] 折りたたみ中は、その block の子要素を描画しない
- [OE-COLLAPSE-003] 子を持たない block は折りたたみ対象にしない
- [OE-COLLAPSE-004] 折りたたみ状態が更新されたら localStorage に保存する
- [OE-COLLAPSE-005] 起動時に保存済みの折りたたみ状態があれば復元する
- [OE-COLLAPSE-006] 折りたたみ中の子孫 block は、キーボード移動と Backspace 結合の対象に含めない
- [OE-COLLAPSE-007] 折りたたみ中の親 block で Enter により先頭の子 block を追加した場合、その親 block を展開して新しい子 block を編集対象にする
- [OE-COLLAPSE-008] 子孫 block を編集中に祖先 block を折りたたんだ場合、編集中の内容を反映して編集モードを終了する

### [未実装] ブロック選択モードの仕様

- ブロック選択の単位はブロック全体とし、ブロック内テキスト範囲とは区別する。
- ブロック選択の範囲は、特に断りがない限り pre-order depth-first の連続区間として扱う。
- 選択モードでは、選択中のブロックを背景色の変化で識別できる。
- 同一の BlockComponent は、同時に編集モードと選択モードに入らない。
- 編集中のブロックから選択モードへ遷移する場合、未保存の編集内容を保存してから遷移する。
- 単一選択は `Shift` を押しながらブロックをクリックしたときに開始する。
- 単一選択中に `Shift + ↑ / ↓` で隣接ブロックを含めた場合、複数選択へ移行する。
- 複数選択中の `Shift + ↑ / ↓` は、anchor を固定したまま focus を前後のブロックへ移動し、anchor からの連続範囲を更新する。
- 選択モードは `Escape` で終了する。
- MVP の一括操作には、`Backspace` による一括削除と、`Tab` / `Shift + Tab` による一括インデント / 一括アウトデントを含める。
- 一括削除後は、削除範囲の直前にあるブロックを選択状態にする。
- コピーと貼り付けの仕様は後続段階で定義する。

## Markdown記法

各ブロック内で扱う Markdown の詳細は [Block Markdown](./block-markdown.md) を参照する。

## テキスト編集

- テキスト入力・削除：編集中のブロック内で通常のテキストエディタと同様に文字を入力・削除できる。
- [未実装] 「Ctrl+C/X/V」：ブロック単位またはテキスト範囲のコピー／カット／ペースト
  - [未実装] ペースト（Ctrl+V）した際は、クリップボードのテキスト/HTMLがサニタイズ＆Markdown化されて挿入される。
- 日本語IME（かな・漢字）での文字入力を阻害しないこと
  - [OE-IME-001] IME変換中の Enter ではブロック分割を発火しない
  - [OE-IME-002] IME変換由来の keyCode 229 を受けた Tab では階層操作を発火せず、ブロック選択に対する一括インデントも発火しない
  - [OE-IME-003] IME変換中の `Process` キーでは ArrowDown によるブロック移動を発火しない
  - [OE-IME-004] IME環境下でもページ参照を挿入しやすくするため、 `Ctrl+[` で `[[]]` を挿入し、カーソルをカッコの中央に配置する。

### ブロック分割・結合

- [OE-SPLIT-001] 編集モード中に「Enter」キーを押した場合、カーソル位置でテキストを前後2つに分割する
  - [OE-SPLIT-002] 前半部分は現在いるブロックに残す
  - 後半部分が新しいブロックとして下に追加されるが、現在いるブロックに子ブロックが
    - [OE-SPLIT-003] ある場合は、子ブロックの先頭に新しいブロックを追加する
    - [OE-SPLIT-004] ない場合は、現在いるブロックの次の兄弟ブロックとして、新しいブロックを追加する
  - カーソルは新ブロックの先頭へ置く
  - [OE-SPLIT-005] hidden root 自体は分割対象にしない
- [OE-JOIN-001] 編集モード中、子ブロックのないブロックにおいて行頭で「Backspace」キーを押した場合、ひとつ上のブロックの末尾にテキストが結合される
  - 結合元のテキストは、キー入力時点の最新の編集内容を使う
  - [OE-JOIN-002] ここでの「ひとつ上のブロック」は、折りたたみ中の子孫 block を除いた可視 block 列において直前にあるブロックを指す
  - [OE-JOIN-003] そのブロックの末尾にカーソル移動する
  - [OE-JOIN-004] 結合元のブロックは削除される
  - [OE-JOIN-005] 子ブロックを持つ場合はBackspace結合が発火せず、子の昇格や削除も行われない

### Undo/Redo/Reset

- [未実装] 編集中 or ブロック構造変更時に「Ctrl+Z（undo）/Ctrl+Y（redo）」：
  → テキスト編集はエディタ内ヒストリー、ブロック移動や階層化などはアプリ側Undoで元に戻す。
- [OE-RESET-001] 「Ctrl+K」: 状態を初期データに戻す
  - `rootBlock` は初期データに置き換える
  - `caretPosition` は `null` に戻す
  - 各 block の `collapsed` は初期データの状態に戻す

## 永続化

- [OE-STORAGE-001] 起動時に localStorage に保存済みの `rootBlock` があれば、それを初期データより優先して読み込む
- [OE-STORAGE-002] `rootBlock` が更新されたら、その内容を localStorage に保存する
- [OE-STORAGE-003] localStorage の保存内容が壊れている場合は、初期データへフォールバックする

## 階層操作（インデント・アウトデント）

- 階層操作は編集モード時のみできるものとする。表示モードの場合は動作しない
- 編集モードで「Tab」キーを押した場合（インデント）
  - [OE-INDENT-001] 前の兄弟ブロックが存在する場合は、その兄弟ブロックの子要素となり、階層が1段深くなる。
    - 階層変更前に、対象ブロックの最新の編集内容を反映する
  - [OE-INDENT-002] 存在しない場合は何も起きない
  - [OE-INDENT-003] インデント後も対象 block は編集モードのままで、editor focus が外れない
- 編集モードで「Shift+Tab」キーを押した場合（アウトデント）
  - [OE-OUTDENT-001] 1段上の階層に移動する。親の直後に配置される。
    - 階層変更前に、対象ブロックの最新の編集内容を反映する
  - [OE-OUTDENT-002] Shift+Tab時に後続兄弟をアウトデント対象の子として吸収し、親直後に単独配置されない
  - [OE-OUTDENT-003] hidden root の直下にある block はアウトデントしない
  - [OE-OUTDENT-004] アウトデント後も対象 block は編集モードのままで、editor focus が外れない

## ブロック移動・複数選択

- 編集モードで「↑/↓」キー：
  - [OE-MOVE-005] ブロック内に1行しかない場合、上／下のブロックを編集モードにする
    - 別ブロックへ移動する前に、移動元ブロックの最新の編集内容を反映する
  - ブロック内に2行以上ある場合、
    - [OE-MOVE-006] 最初/最後の行にある場合、上／下のブロックを編集モードにする
      - 別ブロックへ移動する前に、移動元ブロックの最新の編集内容を反映する
    - [OE-MOVE-007] それ以外の場合、ブロック内で上／下の行に移動する
  - [OE-MOVE-008] 上／下のキー操作で別ブロックへ移動する場合、移動元の行内オフセットを維持する
  - [OE-MOVE-009] 上／下のキー操作で別ブロックへ移動したとき、移動先の行が短い場合はキャレットを移動先行末尾にクランプする
  - [OE-MOVE-010] 上／下のキー操作で別ブロックへ移動したとき、移動先の行が空行の場合はキャレットをその空行先頭に配置する
  - 折りたたみ中の子孫 block は移動先に含めない
  - [未実装] ここでの「行」は本来「画面上の折返し行」を指しているが、実装ではまだそこまで考慮できていない
- 編集モードで「Ctrl+↑」キー：
  - [OE-REORDER-001] 対象ブロックは子孫を保ったまま、同じ親を持つ一つ前の兄弟ブロックと位置を入れ替える
    - 入れ替え前に、対象ブロックの最新の編集内容を反映する
  - [OE-REORDER-002] 先頭の兄弟ブロックは移動しない
- 編集モードで「Ctrl+↓」キー：
  - [OE-REORDER-003] 対象ブロックは子孫を保ったまま、同じ親を持つ一つ後の兄弟ブロックと位置を入れ替える
    - 入れ替え前に、対象ブロックの最新の編集内容を反映する
  - [OE-REORDER-004] 末尾の兄弟ブロックは移動しない
- 編集モードで「←」キーを押した場合
  - [OE-MOVE-001] カーソルがブロック先頭にある場合: 一つ前のブロック末尾に移動する
  - 折りたたみ中の子孫 block は移動先に含めない
  - それ以外の場合: 1文字前に移動する
- 編集モードで「→」キーを押した場合
  - [OE-MOVE-002] カーソルがブロック末尾にある場合: 一つ後のブロック先頭に移動する
  - 折りたたみ中の子孫 block は移動先に含めない
  - それ以外の場合: 1文字後に移動する
- [未実装] ShiftやCtrlクリックで複数ブロック選択、まとめてインデント/削除/移動することができる。
- [OE-MOVE-003] 編集モードで「Ctrl+A」: 行頭へ移動する
- [OE-MOVE-004] 編集モードで「Ctrl+E」: 行末へ移動する
